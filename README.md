# EndlessEngeneering Miniterm

## How do I install these formulae?

`brew install endlessengeneering/miniterm/<formula>`

Or `brew tap endlessengeneering/miniterm` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "endlessengeneering/miniterm"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
